
# Personal Morning Assistant

AI-powered personal assistant for automated daily briefings.

## Sobre o projeto

O Personal Morning Assistant é um assistente pessoal
desenvolvido em Python para automatizar a organização diária.

O sistema consulta compromissos do Google Calendar,
utiliza inteligência artificial para gerar um briefing
personalizado e envia o resumo por e-mail através do Gmail.

## Funcionalidades

- Integração com Google Calendar API
- Integração com Gmail API
- Geração de resumos com OpenAI
- Assistente conversacional com LangChain
- Envio automático de briefings matinais
- Controle de envios duplicados
- Agendamento automático pelo Windows

## Tecnologias

- Python
- OpenAI API
- LangChain
- Google Calendar API
- Gmail API
- OAuth 2.0
- Windows Task Scheduler
